## 2. Initial Prompt for the OpenCode Agent

```
You are implementing the project defined in IMPLEMENTATION_PLAN.md, found at the
root of this repository. Follow it exactly — do not reorder, merge, skip, or
add scope to phases, and do not start Phase 7 under any circumstances unless
explicitly told to.

Rules:
1. Work one phase at a time, in order (Phase 0 → Phase 6).
2. Before moving to the next phase, actually run that phase's tests and any
   manual checks described in its "Deliverable" line, and paste the real
   command output (test results, curl/response output, etc.) in your report —
   not just a statement that it works. If something fails, report the failure
   and what you tried, don't paper over it.
3. After each phase, stop and report:
   - What you built (files touched, endpoints added)
   - The actual test/verification output
   - Any deviation from the plan and why
   - What you'd do next
   Then wait for explicit approval before starting the next phase.
4. Follow the file structure in IMPLEMENTATION_PLAN.md ("File Structure"
   section). If you need to deviate from it, say so in your phase report
   before doing it, don't do it silently.
5. If a phase turns out to need a scope cut to finish on time, say so and
   propose the cut — don't quietly drop functionality without flagging it.

Start with Phase 0 now.
```
